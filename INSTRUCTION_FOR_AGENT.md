# 🤖 Инструкция для ИИ-агента (Rules & Architecture Guide)

Этот документ — главное руководство для любого ИИ-агента при входе в репозиторий **ITCO Dashboard**. Ознакомьтесь с ним перед началом работы над любыми задачами и рефакторингом.

---

## 1. Контекст и назначение проекта

* **Проект**: ITCO Work Shift & Teams Dashboard.
* **Назначение**:
  1. Автоматический учёт рабочих смен и расчёт заработной платы в реальном времени.
  2. Автоматизация отправки утреннего приветствия («Здравствуйте, я на рабочем месте») и вечернего daily-отчёта в Microsoft Teams в один клик.
  3. Просмотр, редактирование и экспорт истории смен в Excel/CSV.
* **Пользователи**: Любой авторизованный сотрудник компании IT Co. (код полностью динамический, без хардкода ФИО, логинов или личных почт).

---

## 2. ⚠️ Критические инварианты проекта (СТРОГИЙ ЗАПРЕТ НА НАРУШЕНИЕ)

1. **ЗАПРЕТ на отправку тестовых сообщений в Teams**:
   * Ни при каких обстоятельствах не слать запросы в боевые чаты Microsoft Teams при отладке и тестировании!
   * В `backend/tests/test_backend.py` все вызовы Teams API (`send_teams_message`, `ensure_active_token`) изолированы моками (`unittest.mock.patch`).
2. **Финансовая математика и правила смен**:
   * Базовый оклад: **35 000 ₽ / месяц** (норма 21 рабочий день = **1 667.00 ₽ / день** за 8 часов, `~0.05788 ₽/сек`).
   * **Правила округления времени**:
     * Официальный старт: **10:00:00**. Приход раньше 10:00 округляется до 10:00:00.
     * Официальное завершение: **18:00:00** (8.0 ч).
     * Время ухода округляется **в пользу сотрудника до полного часа** (уход в 17:31 засчитывается как 18:00, переработка до 19:05 — как 19:00).
     * Переработки сверх 8 часов оплачиваются строго пропорционально ставке.
3. **Чистый UI без «AI-slop» (стиль Refero Design)**:
   * Минималистичный корпоративный интерфейс: чистый фон, тонкие границы `border-slate-200/80`, шрифты `font-sans`, моноширинные цифры `tabular-nums` для таймеров и сумм.
   * **НЕТ**: аляповатым градиентам, прыгающим CSS-анимациям (`scale()`), плавающим микробейджам (`+0.06 ₽`), вызывающим ощущение лагов.
4. **Динамический заголовок вкладки (`useDynamicTitle.ts`)**:
   * В `document.title` в реальном времени бежит секундомер (каждые 50 мс, ~20 FPS) и заработок за текущий день:
     `[01:24:32.4 | +294.10 ₽] ITCO Dashboard`
   * При завершённой смене: `[Завершена | +1 667.00 ₽] ITCO Dashboard`.
5. **Безопасность и изоляция портов**:
   * В `docker-compose.yml` порт привязан строго к `127.0.0.1:8000:8000`. Внешний трафик идёт только через Nginx HTTPS.
   * Никаких паролей, токенов, ключей и персональных данных в Git-коммитах.

## 3. Стек технологий и архитектура

* **Backend**:
  * Python 3.12, FastAPI, Uvicorn.
  * SQLite через `aiosqlite` (файл базы `backend/dashboard.db`).
  * Playwright (Chromium) для браузерной авторизации и тихого автопродления токенов Teams (`proactive_token_keeper` каждые 5 минут).
  * `teams_client.py` для прямого HTTP-взаимодействия с Teams `chatsvc` API (с автоматическим URL-encoding ID тредов).
* **Frontend**:
  * React 18, Vite 6, TypeScript, Tailwind CSS.
  * Lucide React иконки.
  * Модальные окна смен с живым редактированием времени и отчётов.
* **DevOps**:
  * Multi-stage `Dockerfile` (`node:20-slim` для сборки SPA + `python:3.12-slim` для рантайма).
  * GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) — ручной запуск сборки и деплоя на VPS через `workflow_dispatch`.

---

## 4. Команды для разработки и проверки

```bash
# Запуск юнит-тестов бэкенда (всегда проверяйте перед коммитом!)
python -m unittest discover backend/tests

# Сборка фронтенда
cd frontend && npm run build && cd ..

# Локальный запуск приложения
python run.py

# Режим разработки с hot-reload
python run.py --dev

# Запуск в Docker
docker compose up -d --build
```

## 5. Карта файлов и эндпоинтов

| Файл | Назначение |
|---|---|
| `backend/app/main.py` | Эндпоинты FastAPI, CORS, раздача статики SPA, фоновый демон автопродления токена Teams. |
| `backend/app/database.py` | Модели базы данных SQLite, миграции, CRUD смен, расчет заработка и длительности. |
| `backend/app/schemas.py` | Pydantic v2 схемы запросов и ответов API. |
| `backend/app/teams_client.py` | Отправка сообщений в Teams API (`chatsvc`). |
| `backend/app/browser_auth.py` | Авторизация через Playwright, управление блокировками Chromium (`_browser_profile_lock`). |
| `backend/app/tracker_client.py` | Взаимодействие с ITCO Tracker (Huly), сбор проектов и задач, обновление статусов. |
| `backend/app/auth.py` | Проверка пароля и генерация JWT сессий. |
| `backend/tests/test_backend.py` | Модульные тесты эндпоинтов и бизнес-логики. |
| `frontend/src/App.tsx` | Главный компонент состояния, сессии и роутинга вкладок. |
| `frontend/src/components/ShiftView.tsx` | Главный экран: кнопки утренней/вечерней отметки, таймер, поле отчёта. |
| `frontend/src/components/TrackerView.tsx` | Секция ITCO Tracker: Канбан-доска (6 статусов), фильтр проектов, смена статусов задач. |
| `frontend/src/components/HistoryView.tsx` | История смен, фильтрация по месяцам, модальное окно просмотра/редактирования/удаления смен. |
| `frontend/src/components/SettingsModal.tsx` | Настройки Teams, подключение аккаунта, импорт cURL, смена пароля. |
| `frontend/src/hooks/useDynamicTitle.ts` | Хук обновления заголовка вкладки в реальном времени (20 FPS). |
| `.github/workflows/deploy.yml` | Пайплайн ручного деплоя на VPS через GitHub Actions. |

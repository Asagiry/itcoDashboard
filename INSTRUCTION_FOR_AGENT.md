# 🤖 Инструкция для ИИ-агента и руководство по проекту ITCO Dashboard

Данный документ содержит полное описание проекта, архитектуру, бизнес-логику, краткую историю разработки и пошаговое руководство по запуску на **Windows** (при переносе с Linux).

## 1. О проекте и пользователе

* **Пользователь**: Владимир Епишин (Vladimir Epishin, `vepishin@it-co.ru`).
* **Компания**: IT Co.
* **Назначение дашборда**:
  1. Учёт рабочих смен и расчёт зарплаты в реальном времени.
  2. Автоматизация отправки утреннего приветствия и вечернего daily-отчёта в Microsoft Teams в один клик.
* **Рабочий график и правила**:
  * Официальный старт рабочего дня: **10:00**.
  * Официальное завершение: **18:00** (норма дня — **8.0 часов**).
  * Ранний приход до 10:00 округляется до 10:00.
  * Время ухода округляется в пользу сотрудника до полного часа (например, уход в 17:31 округляется до 18:00, переработка до 19:05 — до 19:00).
* **Зарплатные ставки**:
  * Оклад в договоре: **35 000 ₽ / месяц**.
  * Дневная ставка за 8-часовую смену: **1 667.00 ₽** (`~0.05788 ₽/сек`).
  * Переработки оплачиваются пропорционально отработанным часам.

## 2. Краткая история разработки и контекст диалога

В ходе разработки с Владимиром были приняты следующие ключевые решения и устранены баги:

1. **Строгий запрет на тестовые сообщения в Teams**:
   * Ни при каких обстоятельствах нельзя отправлять тестовые пинги или отчёты в рабочие чаты Teams.
   * В `backend/tests/test_backend.py` все сетевые вызовы Teams (`send_teams_message`, `ensure_active_token`) наглухо закрыты моками (`unittest.mock.patch`).
2. **Дизайн без «AI-slop» (чистый, минималистичный UI)**:
   * Удалены искусственные метки «Шаг 1, 2, 3», капс, «Цель месяца (35 000 ₽)» и лишняя вложенность контейнеров.
   * Удалены раздражающие прыгающие CSS-анимации (`scale(1.18)`) и всплывающие микробейджи (`+0.06 ₽`), вызывавшие ощущение лагов и низкого FPS.
   * Таймер переведён на частоту **50 мс (~20 FPS)** с отображением десятых долей `.d` (`00:00:00.0`) и фиксированной шириной цифр `tabular-nums`.
3. **Динамический Title вкладки (`useDynamicTitle.ts`)**:
   * В названии вкладки браузера в реальном времени бежит секундомер с десятыми долями и начисление рублей строго **за сегодня с копейками**:
     `[00:43:44.1 | +151.89 ₽] ITCO Dashboard`
   * Работает глобально, даже если вкладка свёрнута или открыт VS Code / Teams.
   * При завершении смены показывает: `[Завершена | +1 667.00 ₽] ITCO Dashboard`.
4. **Интеграция с Microsoft Teams без повторных ручных входов**:
   * Утреннее сообщение уходит руководителю: `«Здравствуйте, я на рабочем месте»`.
   * Вечернее сообщение отправляется в чат отчётов команды: строго чистый текст из поля «Что я сегодня сделал» (без лишних префиксов и дат).
   * Идентификаторы тредов автоматически URL-кодируются (`19%3A...%40thread.v2`), предотвращая ошибки Microsoft 404 (`Invalid ThreadId.`).
   * Фоновый демон в `lifespan` (`proactive_token_keeper`) проверяет токен каждые 5 минут и заблаговременно тихо обновляет его через Chromium, если осталось менее 60 минут.
5. **Защита от блокировок Chromium (`ProcessSingleton / SingletonLock`)**:
   * Добавлена функция `cleanup_browser_profile_locks()` и глобальный асинхронный мьютекс `_browser_profile_lock`.
   * Получение списка контактов/чатов переведено на быстрый прямой HTTP API Teams (`chatsvc`), исключая лишний запуск браузера.

## 3. Стек технологий

* **Backend**: Python 3.10+, FastAPI, Uvicorn, SQLite (`aiosqlite`), HTTPX, Playwright.
* **Frontend**: React 18, Vite, TypeScript, TailwindCSS, Lucide Icons.
* **База данных**: `backend/dashboard.db` (SQLite). **ВАЖНО**: в ней хранятся все смены за сентябрь 2026, текущие настройки чатов Teams и сохранённый токен.

## 4. Пошаговая инструкция по запуску на Windows

### Шаг 1. Убедитесь в наличии окружения
На Windows должны быть установлены:
1. **Python 3.10+** (при установке обязательно отметьте галочку *«Add Python to PATH»*).
2. **Node.js 18+** (включает `npm`).
3. Браузер **Google Chrome**.

### Шаг 2. Установка зависимостей Python
Откройте PowerShell / CMD в папке проекта и выполните:
```bash
pip install -r backend/requirements.txt
```
*(Опционально)* Если на Windows Playwright попросит установить браузерные зависимости:
```bash
playwright install chromium
```

### Шаг 3. Установка зависимостей фронтенда и сборка
В той же папке проекта:
```bash
cd frontend
npm install
npm run build
cd ..
```
*После этого в `frontend/dist` появится готовый продакшен-бандл, который FastAPI будет раздавать автоматически.*

### Шаг 4. Запуск дашборда
Запустите скрипт:
* Двойным кликом по файлу **`start.bat`**
* Либо в консоли:
```bash
python run.py
```

Дашборд автоматически откроется в браузере по адресу:
👉 **`http://127.0.0.1:8000`**

## 5. Важные файлы проекта

| Файл / Папка | Описание |
|---|---|
| `backend/dashboard.db` | База данных SQLite с историей смен, настройками Teams и ставками. Обязательна к сохранению! |
| `backend/app/main.py` | Эндпоинты FastAPI (`/api/shifts/*`, `/api/settings`, lifespan фоновый демон). |
| `backend/app/teams_client.py` | HTTP-клиент для отправки сообщений в Microsoft Teams chatsvc API. |
| `backend/app/browser_auth.py` | Авторизация через браузер Playwright, фоновое авто-продление токена. |
| `backend/app/database.py` | Работа с базой SQLite, миграции и CRUD смен. |
| `backend/tests/test_backend.py` | Юнит-тесты с моками Teams API. |
| `frontend/src/App.tsx` | Корневой компонент, подключение живого заголовка вкладки. |
| `frontend/src/components/ShiftView.tsx` | Главный экран: 3 карточки смены + поле отчёта с автосохранением. |
| `frontend/src/components/HistoryView.tsx` | История всех смен, фильтр по месяцам, экспорт в Excel/CSV. |
| `frontend/src/components/SettingsModal.tsx` | Модальное окно настроек Teams и статуса аккаунта. |
| `frontend/src/hooks/useDynamicTitle.ts` | Хук реального времени для динамического заголовка вкладки. |
| `run.py` | Единый лаунчер (авто-очистка занятого порта, проверка сборки, запуск). |
| `start.bat` | Быстрый запуск для Windows в один клик. |
| `start.sh` | Запуск для Linux/macOS. |

## 6. Памятка для ИИ-ассистента
* **НЕ отправлять тестовые пинги в Teams**.
* **НЕ ломать расчет зарплаты**: ставка фиксирована из договора (35 000 ₽ / 1 667 ₽).
* **Сохранять минималистичный стиль**: избегать градиентных рамок, лишних бэйджей и анимаций, отвлекающих от работы.

# ITCO Work Shift & Teams Dashboard

Корпоративный веб-сервис для автоматизации учёта рабочего времени и отправки ежедневных отчётов в Microsoft Teams (чат руководителя и дейли-чат команды).

Разработан в чистом светлом корпоративном стиле (**Refero Design style**) с использованием **FastAPI (Python)** на бэкенде и **React + TypeScript + Tailwind CSS** на фронтенде.

---

## Основные возможности

1. **Кнопка «Я на смене» (Шаг 1 • Утро)**:
   - В 10:00 утра сотрудник нажимает одну кнопку.
   - Сервис отправляет в чат с руководителем сообщение:  
     `«Здравствуйте, я на рабочем месте»`.
   - Кнопка **блокируется до следующего дня**, предотвращая повторные нажатия.
   - Фиксируется точное время начала рабочего дня и запускается живой таймер нахождения на смене.

2. **Кнопка «Завершить смену» (Шаг 2 • Вечер)**:
   - Поле **«Что я сегодня сделал»** для ввода списка выполненных задач.
   - Встроенный генератор структурированного шаблона отчёта (`Выполнено`, `В процессе`, `Блокеры`).
   - Автосохранение черновика отчёта в реальном времени.
   - Отправка отчёта в отдельный командный **дейли-чат** Teams.
   - Фиксация времени окончания смены и блокировка обеих кнопок до полуночи.

3. **Два независимых чата Teams в Настройках**:
   - **Чат с директором**: предустановлен URL для утренних отметок.
   - **Дейли-чат команды**: настраиваемый URL для ежедневных отчётов.

4. **Гибкая авторизация Teams**:
   - Поддержка `Authorization: Bearer <token>`, `Authentication: skypetoken=<token>` или `x-skypetoken`.
   - Поддержка произвольных дополнительных заголовков (JSON).
   - **Умный импорт cURL**: возможность скопировать запрос из вкладки Network DevTools браузера и в один клик распарсить URL, токен и headers.
   - Кнопка проверки соединения (**«Тест отправки»**).

5. **История и Экспорт**:
   - **История отчётов**: интерактивная таблица всех смен, времени начала/окончания, отработанных часов и текста отчётов с возможностью быстрого копирования.
   - **Экспорт в Excel**: раздел предварительного просмотра структуры данных и мгновенной выгрузки в `.csv` (Excel).
   - **Сброс дня для тестов**: в настройках доступна кнопка сброса текущего дня для отладки.

## Быстрый запуск

### 1. Стандартный запуск (Готовое приложение)
```bash
./start.sh
```
или:
```bash
python3 run.py
```
Приложение автоматически проверит сборку фронтенда и откроет дашборд в браузере по адресу:  
👉 **http://127.0.0.1:8000**

### 2. Режим разработки (Hot-reload для Python и React)
```bash
python3 run.py --dev
```
В этом режиме параллельно запускаются Uvicorn на порту `8000` и Vite dev-сервер на порту `5173`.

## Как скопировать токен Teams из браузера

1. Откройте Teams в браузере (https://teams.live.com или веб-клиент Teams).
2. Нажмите `F12` (или `Ctrl+Shift+I`) и перейдите на вкладку **Network (Сеть)**.
3. Отправьте любое сообщение в любой чат.
4. В списке сетевых запросов найдите запрос к `messages`.
5. Кликните правой кнопкой мыши: **Copy → Copy as cURL**.
6. В запущенном дашборде откройте **Настройки → Импорт cURL** и нажмите **«Распарсить и применить»**.
7. Все URL и токены заполнятся автоматически!

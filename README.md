# ITCO Work Shift & Teams Dashboard

Современный корпоративный веб-сервис для автоматизации учёта рабочего времени, расчёта заработной платы в реальном времени и отправки ежедневных статус-отчётов в Microsoft Teams (чат руководителя и дейли-чат команды).

Разработан в чистом минималистичном светлом корпоративном стиле (**Refero Design System**) на базе **FastAPI (Python 3.12)** и **React 18 + TypeScript + Tailwind CSS**.

---

## 🚀 Основные возможности

### 1. Учёт смен и автоматизация Teams
* **«Я на смене» (Утренний старт)**:
  * В 10:00 утра сотрудник нажимает одну кнопку.
  * Сервис отправляет в чат руководителя сообщение: `«Здравствуйте, я на рабочем месте»`.
  * Кнопка блокируется до следующего дня, предотвращая случайные повторные отправки.
  * Фиксируется точное время начала смены и запускается живой таймер с начислением зарплаты.
* **«Завершить смену» (Вечерний отчёт)**:
  * Текстовое поле **«Что я сегодня сделал»** для описания выполненных задач.
  * Встроенный генератор структурированного шаблона отчёта (*Выполнено / В процессе / Блокеры*).
  * Автосохранение черновика отчёта в реальном времени (`localStorage`).
  * Отправка чистого текста отчёта в **дейли-чат команды** Teams.
  * Фиксация времени завершения смены и блокировка кнопок до полуночи.

### 2. Финансовый трекер и правила начисления
* **Фиксированный оклад**: 35 000 ₽ / месяц (при норме 21 рабочий день = **1 667.00 ₽ / день**, `~0.05788 ₽/сек`).
* **Правила округления смен**:
  * Официальный интервал: с **10:00** до **18:00** (8.0 часов).
  * Ранний приход до 10:00 автоматически приводится к 10:00:00.
  * Время ухода округляется в пользу сотрудника до полного часа (например, уход в 17:31 засчитывается как 18:00, переработка до 19:05 — как 19:00).
  * Переработки сверх 8 часов оплачиваются пропорционально ставке.

### 3. Живой заголовок вкладки (Live Dynamic Title)
* В заголовке вкладки браузера в реальном времени (каждые 50 мс, ~20 FPS) отображается секундомер с десятыми долями и начисление заработка за сегодня:
  `[01:24:32.4 | +294.10 ₽] ITCO Dashboard`
* Работает глобально, даже если вкладка свёрнута или активны другие окна.
* При завершении смены показывает итоговый статус: `[Завершена | +1 667.00 ₽] ITCO Dashboard`.

### 4. Редактирование истории смен и экспорт
* **Интерактивная история смен**: таблица всех смен по месяцам со статусами, отработанным временем и суммами.
* **Полноценное редактирование смен**:
  * Корректировка времени начала (`start_time`) и окончания (`end_time`).
  * Редактирование текста дневного отчёта.
  * Автоматический пересчёт отработанных часов и заработка.
  * Возможность удаления ошибочных смен с подтверждением.
* **Экспорт в Excel**: предпросмотр структуры данных и мгновенная выгрузка всей истории в файл `.csv` (Excel).

### 5. Интеграция и авторизация в Microsoft Teams
* **Авторизация**:
  * Поддержка входа через email-код (`teams_email_login.py`).
  * Интеграция через Playwright-браузер с фоновым тихим обновлением токенов (`proactive_token_keeper` каждые 5 минут).
  * Ручной импорт cURL-запроса из DevTools Network.
* **Два независимых чата**:
  * Чат с руководителем (утренние приветствия).
  * Дейли-чат команды (вечерние отчёты).
* **Автоматическое кодирование URL**: корректная обработка служебных символов в ID тредов (`19%3A...%40thread.v2`), предотвращающая ошибку Microsoft `404 Invalid ThreadId`.

## 🛠 Стек технологий

* **Backend**: Python 3.12, FastAPI, Uvicorn, SQLite (`aiosqlite`), HTTPX, Playwright, Pydantic v2, Python-dotenv.
* **Frontend**: React 18, Vite 6, TypeScript, Tailwind CSS, Lucide Icons, Headless UI.
* **DevOps & Security**: Docker (Multi-stage build), Docker Compose, Nginx Reverse Proxy (SSL Let's Encrypt), GitHub Actions CI/CD.

---

## 🔒 Безопасность и конфигурация

* **Изоляция портов**: контейнер привязан строго к `127.0.0.1:8000:8000`. Прямой внешний HTTP-доступ к порту 8000 закрыт; весь трафик идёт через Nginx по HTTPS.
* **Защита от утечек секретов**:
  * Все токены, пароли и личные данные вынесены в переменные окружения `.env`.
  * Репозиторий очищен от PII и секретов. Создан файл [.env.example](.env.example).
  * Настроен строгий `.gitignore`, исключающий `.env`, локальные базы данных, дампы переписок и JS-бандлы.

## 🚀 Инструкция по установке и запуску

### 1. Локальный запуск (Windows)

#### Требования:
* Python 3.10+
* Node.js 18+ (npm)
* Google Chrome

#### Установка:
```bash
# 1. Клонирование репозитория
git clone https://github.com/Asagiry/itcoDashboard.git
cd itcoDashboard

# 2. Установка зависимостей Python
pip install -r backend/requirements.txt
playwright install chromium

# 3. Установка зависимостей и сборка фронтенда
cd frontend
npm install
npm run build
cd ..

# 4. Создание файла конфигурации
copy .env.example .env
```

#### Запуск:
* Двойным кликом по файлу **`start.bat`**
* Либо командой:
```bash
python run.py
```
*В режиме разработки с горячей перезагрузкой:*
```bash
python run.py --dev
```
Дашборд откроется по адресу: 👉 **http://127.0.0.1:8000**

---

### 2. Локальный запуск (Linux / macOS)

```bash
chmod +x start.sh
./start.sh
```

---

### 3. Запуск через Docker

```bash
docker compose up -d --build
```
Сервис будет доступен локально на `http://127.0.0.1:8000`.

## 🔄 Деплой на VPS (GitHub Actions)

В проекте настроен ручной пайплайн деплоя через GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

### Необходимые секреты репозитория (Repository Secrets):
В настройках GitHub репозитория (`Settings -> Secrets and variables -> Actions -> New repository secret`):
* `VPS_HOST`: IP-адрес сервера (например, `185.73.215.222`)
* `VPS_USERNAME`: Пользователь SSH (например, `root`)
* `VPS_PASSWORD`: Пароль пользователя (либо `VPS_SSH_KEY` с приватным SSH-ключом)

### Запуск деплоя:
1. Перейдите во вкладку **Actions** в GitHub.
2. В левой колонке выберите **«Deploy to VPS»**.
3. Нажмите кнопку **«Run workflow»**.
4. *(Опционально)* Отметьте `no_cache` для чистой пересборки без использования кэша Docker.
